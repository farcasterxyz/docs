# Hello World

Create your Farcaster account programmatically and publish your first "Hello World" message.

The example shows you how to:

- Make onchain transactions to create an account
- Rent a storage unit so you can publish messages
- Add an account key to sign messages, with a gasless `KEY_ADD` message
- Acquire an fname for your account
- Create, sign and publish messages

This example can be checked out as a fully functional
repository [here](https://github.com/farcasterxyz/hub-monorepo/tree/main/packages/hub-nodejs/examples/hello-world).

### Requirements

- A Snapchain node to submit messages to. Your own [read node](https://snapchain.farcaster.xyz/guides/running-a-node) works: read nodes accept messages and relay them to the validators.
- An ETH wallet with a little ETH on [OP Mainnet](https://www.optimism.io/) to register the account. The price comes from `IdGateway.price()` and includes one unit of storage (about $0.20 in October 2026).
- An ETH RPC URL for OP Mainnet (e.g. via [Alchemy](https://www.alchemy.com/), [Infura](https://www.infura.io/) or [QuickNode](https://www.quicknode.com/)).

## 1. Set up constants

```typescript
import {
  ID_GATEWAY_ADDRESS,
  idGatewayABI,
  ID_REGISTRY_ADDRESS,
  idRegistryABI,
  FarcasterNetwork,
  MessageType,
  NobleEd25519Signer,
  ViemLocalEip712Signer,
  getFarcasterTime,
  makeKeyAdd,
  makeKeyAddBody,
} from '@farcaster/hub-web';
import { zeroAddress } from 'viem';
import { optimism } from 'viem/chains';

/**
 * Populate the following constants with your own values
 */
const MNEMONIC = '<REQUIRED>';
const OP_PROVIDER_URL = '<REQUIRED>'; // Alchemy or Infura url
const RECOVERY_ADDRESS = zeroAddress; // Optional, using the default value means the account will not be recoverable later if the mnemonic is lost
const ACCOUNT_KEY_PRIVATE_KEY: Hex = zeroAddress; // Optional, using the default means a new account key will be created each time

// Any Snapchain node accepts messages and relays them to the validators, including
// a read node you run yourself: https://snapchain.farcaster.xyz/guides/running-a-node
const HUB_URL = 'your-node.example.com:3383'; // host and gRPC port of a Snapchain node
const HUB_USERNAME = ''; // Username for auth, leave blank if not using TLS
const HUB_PASS = ''; // Password for auth, leave blank if not using TLS
const USE_SSL = false; // set to true if the node is behind TLS (hosted providers usually are)
const FC_NETWORK = FarcasterNetwork.MAINNET; // Network of the node

const CHAIN = optimism;

const IdGateway = {
  abi: idGatewayABI,
  address: ID_GATEWAY_ADDRESS,
  chain: CHAIN,
};
const IdContract = {
  abi: idRegistryABI,
  address: ID_REGISTRY_ADDRESS,
  chain: CHAIN,
};
```

## 2. Register and pay for storage

Create a function to register an FID and pay for storage. This function will check if the account already has an FID
and return early if so.

```typescript
const getOrRegisterFid = async (): Promise<number> => {
  const balance = await walletClient.getBalance({ address: account.address });
  // Check if we already have an fid
  const existingFid = (await walletClient.readContract({
    ...IdContract,
    functionName: 'idOf',
    args: [account.address],
  })) as bigint;

  if (existingFid > 0n) {
    return parseInt(existingFid.toString());
  }

  const price = await walletClient.readContract({
    ...IdGateway,
    functionName: 'price',
  });
  if (balance < price) {
    throw new Error(
      `Insufficient balance to rent storage, required: ${price}, balance: ${balance}`
    );
  }
  const { request: registerRequest } = await walletClient.simulateContract({
    ...IdGateway,
    functionName: 'register',
    args: [RECOVERY_ADDRESS],
    value: price,
  });
  const registerTxHash = await walletClient.writeContract(registerRequest);
  const registerTxReceipt = await walletClient.waitForTransactionReceipt({
    hash: registerTxHash,
  });
  // Now extract the FID from the logs
  const registerLog = decodeEventLog({
    abi: idRegistryABI,
    data: registerTxReceipt.logs[0].data,
    topics: registerTxReceipt.logs[0].topics,
  });
  const fid = parseInt(registerLog.args['id']);
  return fid;
};

const fid = await getOrRegisterFid();
```

## 3. Add an account key

An account key is an Ed25519 key pair that signs messages for the account. You add it with a `KEY_ADD` message,
which costs no gas: the custody address signs an EIP-712 authorization, the new key signs the message, and you submit
it to a node like any other message.

Every account key names the fid of the app that requested it. Here the account is its own app, so `makeKeyAddBody`
signs that request with the same custody key. The key can only sign the message types listed in `scopes`, and it
expires after `ttl` seconds without use (at most 90 days).

```typescript
const submitMessage = async (resultPromise: HubAsyncResult<Message>) => {
  const result = await resultPromise;
  if (result.isErr()) {
    throw new Error(`Error creating message: ${result.error}`);
  }
  const submitted = await hubClient.submitMessage(result.value);
  if (submitted.isErr()) {
    throw new Error(`Error submitting message: ${submitted.error}`);
  }
};

const getOrRegisterAccountKey = async (fid: number) => {
  if (ACCOUNT_KEY_PRIVATE_KEY !== zeroAddress) {
    // If a private key is provided, we assume the account key was already added
    return fromHex(ACCOUNT_KEY_PRIVATE_KEY, 'bytes');
  }

  const privateKey = ed25519.utils.randomPrivateKey();
  const accountKey = new NobleEd25519Signer(privateKey);
  const publicKey = (await accountKey.getSignerKey())._unsafeUnwrap();

  // Each KEY_ADD uses the next nonce for the account
  const signers = await hubClient.getSignersByFid({ fid, requesterFids: [] });
  if (signers.isErr()) {
    throw new Error(`Error reading nonce: ${signers.error}`);
  }

  const body = await makeKeyAddBody(
    {
      fid: BigInt(fid),
      key: publicKey,
      scopes: [MessageType.CAST_ADD, MessageType.CAST_REMOVE, MessageType.USER_DATA_ADD],
      ttl: 30 * 24 * 60 * 60, // 30 days without use
      nonce: signers.value.currentUserNonce + 1,
      deadline: getFarcasterTime()._unsafeUnwrap() + 60 * 60, // 1 hour from now
    },
    new ViemLocalEip712Signer(account) // the custody address
  );
  if (body.isErr()) {
    throw new Error(`Error building KEY_ADD: ${body.error}`);
  }

  await submitMessage(makeKeyAdd(body.value, { fid, network: FC_NETWORK }, accountKey));
  // The key can sign messages once a validator includes the KEY_ADD in a block, usually within seconds
  await new Promise((resolve) => setTimeout(resolve, 10000));
  return privateKey;
};

const accountPrivateKey = await getOrRegisterAccountKey(fid);
```

Apps that add keys for other users still need a signature from the user's custody address. See
[Create an account key](/developers/guides/accounts/create-account-key) for the onchain Key Gateway flow.

## 4. Register an fname

Now that the onchain actions are complete, let's register an fname using the farcaster offchain fname registry.
Registering an fname requires a signature from the custody address of the fid.

```typescript
const registerFname = async (fid: number) => {
  try {
    // First check if this fid already has an fname
    const response = await axios.get(
      `https://fnames.farcaster.xyz/transfers/current?fid=${fid}`
    );
    const fname = response.data.transfer.username;
    return fname;
  } catch (e) {
    // No username, ignore and continue with registering
  }

  const fname = `fid-${fid}`;
  const timestamp = Math.floor(Date.now() / 1000);
  const userNameProofSignature = await walletClient.signTypedData({
    domain: USERNAME_PROOF_DOMAIN,
    types: USERNAME_PROOF_TYPE,
    primaryType: 'UserNameProof',
    message: {
      name: fname,
      timestamp: BigInt(timestamp),
      owner: account.address,
    },
  });

  const response = await axios.post('https://fnames.farcaster.xyz/transfers', {
    name: fname, // Name to register
    from: 0, // Fid to transfer from (0 for a new registration)
    to: fid, // Fid to transfer to (0 to unregister)
    fid: fid, // Fid making the request (must match from or to)
    owner: account.address, // Custody address of fid making the request
    timestamp: timestamp, // Current timestamp in seconds
    signature: userNameProofSignature, // EIP-712 signature signed by the current custody address of the fid
  });
  return fname;
};

const fname = await registerFname(fid);
```

Note that this only associated the name to our fid, we still need to set it as our username.

## 5. Write to the node

Finally, we're now ready to submit messages to the node. First, we shall set the fname as our username. And then post a
cast.

```typescript
const accountKey = new NobleEd25519Signer(accountPrivateKey);
const dataOptions = {
  fid: fid,
  network: FC_NETWORK,
};
const userDataUsernameBody = {
  type: UserDataType.USERNAME,
  value: fname,
};
// Set the username
await submitMessage(
  makeUserDataAdd(userDataUsernameBody, dataOptions, accountKey)
);

// Post a cast
await submitMessage(
  makeCastAdd(
    {
      text: 'Hello World!',
    },
    dataOptions,
    accountKey
  )
);
```

Now, you can view your profile on any farcaster client. To see it on Farcaster, visit `https://farcaster.xyz/@<fname>`
